Workflow satisfiability with OR-Tools

Solves the workflow satisfiability problem with authorisation, binding and separation of duty, at-most-k and one-team constraints. A custom callback stops at two solutions to test uniqueness, and the solver beat the reference runtimes on the seven timed instances.

A Java hyper-heuristic for the Minimum Set Cover problem. Reinforcement learning selects between four hill climbers (next descent, steepest descent, Davis’s bit and random mutation) with delta evaluation. Reached a best objective value of 5 in all five trials on both benchmark instances.
